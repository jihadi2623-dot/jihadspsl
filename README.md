# For Mim — A Little Universe of Love

## Run locally
Open `index.html` in a modern browser. For best results, use a local static server or publish the files as a static site.

## Publish with Cloudflare Pages
Upload the contents of this folder (the files directly inside it, including `index.html` and `soft-love-song.mp3`) using Cloudflare Pages Direct Upload.

## Music
A soft original romantic instrumental is included as `soft-love-song.mp3`. Tap **♫ SOUND OFF** in the top bar to start it. Browsers on phones generally require a tap before audio can play. Tap again to pause. The song loops throughout the site as you move between pages.

## Notes
Keep `index.html`, `style.css`, `script.js`, and `soft-love-song.mp3` together in the same folder.
